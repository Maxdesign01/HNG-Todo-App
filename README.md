# My Tasks

A simple, responsive Todo app with optional date and time reminders. Tasks are stored in your browser using localStorage, so no account or backend is required.

## Features

- Add, complete, and delete tasks
- Filter by all, active, or completed tasks
- Set, edit, and remove optional reminders
- See upcoming, due soon, and overdue reminders
- Get an in-app reminder when a task becomes due while the app is open
- Responsive layout for mobile, tablet, and desktop
